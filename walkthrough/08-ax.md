# ax.py — Accessibility API helpers

[ax.py](../ax.py) wraps the macOS **Accessibility** API ("AX"). With the Accessibility
permission, an app can ask other apps about their interface: which window and text field is
focused, where they are on screen, where the cursor is, and what text is in a field. Screen
readers like VoiceOver use the same API. Parole uses it for the bubble's position
(bubble.py), the text around the cursor (context.py) and learning (learning.py).

---

## Lines 1–11: docstring

Important detail: AX measures from the **top-left** of the main screen (y goes down); AppKit
measures from the **bottom-left** (y goes up). `frame()` and `caret_frame()` convert to
AppKit's `(x, y, width, height)`.

## Lines 13–28: imports and constant

```python
from AppKit import NSScreen, NSWorkspace      # screens; running apps
from ApplicationServices import (
    AXUIElementCopyAttributeValue,               # read an attribute ("AXRole", "AXValue"...)
    AXUIElementCopyParameterizedAttributeValue,  # read an attribute that takes a parameter
    AXUIElementCreateApplication,                # get the AX element of an app from its PID
    AXUIElementSetMessagingTimeout,              # max time to wait for an app to answer
    AXValueCreate, AXValueGetValue,              # pack / unpack C structs (ranges, points...)
    kAXErrorSuccess,                             # the "no error" code (0)
    kAXValueCFRangeType, kAXValueCGPointType, kAXValueCGRectType, kAXValueCGSizeType,
)
TIMEOUT = 0.05  # never wait more than 50 ms for a slow app
```
An **AX element** (`AXUIElement`) is a handle to one piece of another app's interface: the
app, a window, a text field...

## Lines 31–38: `attribute` and `parameterized`

```python
def attribute(element, name):
    error, value = AXUIElementCopyAttributeValue(element, name, None)
    return value if error == kAXErrorSuccess else None
```
The C function writes its result through a pointer; PyObjC turns that into a returned tuple
`(error, value)` (we pass `None` for the pointer). Return the value, or `None` if the app
didn't answer. `parameterized` is the same for attributes that need an argument (e.g. "the
text in this range").

## Lines 41–49: `_frontmost_app`

```python
app = NSWorkspace.sharedWorkspace().frontmostApplication()
if app is None:
    return None
element = AXUIElementCreateApplication(app.processIdentifier())
AXUIElementSetMessagingTimeout(element, TIMEOUT)
return element
```
Find the app in front, get its process ID (PID), create its AX element, and set the 50 ms
timeout. The comment explains that asking the frontmost app directly is more reliable than
the "system-wide" element (which sometimes fails with error -25204).

## Lines 52–60: `focused_element`, `focused_window`

Ask the front app for its `"AXFocusedUIElement"` (the control with keyboard focus — usually
a text field) or `"AXFocusedWindow"`. `... if app is not None else None` avoids calling
`attribute` on `None`.

## Lines 63–69: `selected_range`

```python
value = attribute(field, "AXSelectedTextRange")
if value is None:
    return None
ok, text_range = AXValueGetValue(value, kAXValueCFRangeType, None)
return tuple(text_range) if ok else None
```
The cursor/selection is returned as an `AXValue` wrapping a C `CFRange` struct.
`AXValueGetValue` unpacks it (again, out-parameter → tuple). Result: `(start, length)`;
`length` is 0 when it's just a cursor.

## Lines 72–74: `_to_appkit`

```python
top = NSScreen.screens()[0].frame().size.height
return (x, top - y - height, width, height)
```
`screens()[0]` is the primary screen (with the menu bar), whose top-left is AX's origin.
Flipping: AppKit's y of the rectangle's **bottom** = screen height − AX's y of its top − its
height.

```python
if position is None or size is None:
    return None
_, point = AXValueGetValue(position, kAXValueCGPointType, None)
_, extent = AXValueGetValue(size, kAXValueCGSizeType, None)

```
Read the element's top-left position and size, unpack the `CGPoint`/`CGSize`, convert.

## Lines 87–102: `caret_frame`

```python
text_range = selected_range(field)
if text_range is None:
    return None
start = text_range[0]
for candidate in ((start, 0), (max(start - 1, 0), 1)):
    bounds = parameterized(field, "AXBoundsForRange", AXValueCreate(kAXValueCFRangeType, candidate))
    if bounds is None:
        continue
    _, rect = AXValueGetValue(bounds, kAXValueCGRectType, None)
    if rect.size.height > 0:
        return _to_appkit(rect.origin.x, rect.origin.y, rect.size.width, rect.size.height)
return None
```
Ask "where on screen is this range of text drawn?". First try the empty range at the cursor;
some apps only answer for a real character, so then try the character before it. A rectangle
with zero height is not useful, so it's skipped.

## Lines 105–111: `role`, `is_secure`

`role` returns e.g. `"AXTextField"`, `"AXTextArea"`, `"AXButton"`.
`is_secure` returns `True` for password fields: either the role or the subrole is
`"AXSecureTextField"`. `"x" in (a, b)` checks whether `"x"` equals either.

## Lines 114–120: `character_count`

```python
count = attribute(field, "AXNumberOfCharacters")
if count is None:
    value = attribute(field, "AXValue")
    count = len(value) if isinstance(value, str) else None
return count
```
Ask for the number of characters; if the app doesn't say, read the whole text (`AXValue`)
and count it — only if it really is a string.

## Lines 123–135: `text`

```python
if length <= 0:
    return ""
value = parameterized(field, "AXStringForRange", AXValueCreate(kAXValueCFRangeType, (start, length)))
if value:
    return str(value)
```
